# GNN-001 Spec v0.1 (draft for review, not sealed)

Stage S4b (GNN training graphs), family F3 (availability and
degradation) with targeted variants. This spec implements charter
v0.4 section 10 GNN-001. Unlike the RAG and GraphRAG arms, the subject
here is trained by the benchmark itself, in Rust, under the graph
crate. Training is local and small, so this arm carries no provider
spend and no funded cap. Its discipline is seed and recipe control
instead.

## Data

- One small standard citation graph with a stated licence, named at
  seal time. Planning candidate: Cora (2,708 nodes, 5,429 edges, 7
  classes, 1,433 binary features, with the standard Planetoid split of 140
  training, 500 validation, 1,000 test nodes). The dataset licence
  and source are recorded in the data manifest at seal, and the raw
  files are hashed into the seal like any deterministic artifact.
- One synthetic planted-community graph generated by wyrd-graph,
  where ground truth is exact: communities planted with stated
  within- and between-community edge probabilities, prototype
  features with stated noise, in the shape of the GCN spike's
  generator but at citation scale and with the generator version and
  seed pinned in the seal. The synthetic graph is where targeted
  claims are read, because only there is every node's true class
  known by construction rather than by a dataset's labels.

## Trainer and the reference-parity bar

- The subject is a two-layer GCN trained in Rust in the graph crate,
  the architecture the 2026-11-03 spike validated (hand-derived
  backprop, gradient agreement with finite differences at 5.59e-8
  against a bar of 1e-4). Hidden width, learning rate, epochs, and
  weight decay are pinned in the seal and identical across arms and
  seeds. Full-batch training, so a run is deterministic given its
  seed and its graph version.
- Before this spec can seal, the charter's reference-parity bar must
  be discharged on the named citation graph: the in-Rust trainer
  matches a stated reference implementation's test accuracy on
  identical data and split within 2 percentage points. The reference
  is named at seal time with its version, and both accuracies are
  printed in the seal record. The spike's synthetic accuracy does not
  discharge this bar, and the spec does not pretend it does.
- Three training seeds per arm version, per the charter. Rates carry
  per-seed values, and aggregation follows charter section 4.

## Arms and ladders

Two poison dimensions, run as separate ladders, never mixed in one
arm version.

- Node injection ladder (F3 and targeted): doses of 0, 5, 10, 25, 50
  injected nodes, nested, each injected node carrying a stated edge
  budget (planning figure: up to 5 edges, attached by a stated rule
  to existing nodes) and features drawn by a stated generator rule.
  Injected nodes are new graph citizens, added through the graph
  crate's injection path with its full audit record, so the graph
  diff between arm versions is exact by construction.
- Label-flip ladder: 0, 10, 25, 50, 100 flipped labels on training
  nodes, in absolute counts as the ladder's units, per the charter.
  The percentage of labelled nodes each count represents is derived
  and reported alongside, never as the ladder itself. Flips are
  nested and seeded: the first d entries of the sealed flip list.
- Arm C is dose 0 of each ladder. Arm S (sham) is mandatory for S4b
  per charter section 5, and for node injection it is benign node
  injection matched for count and edge budget, with features drawn
  from the clean feature distribution and labels from the clean label
  distribution. Arm S is the only way to separate poison from graph
  growth, and it runs at every injection dose. For the label-flip
  ladder the sham is a matched relabelling that permutes labels among
  training nodes of the same true class where the data supports it,
  or is recorded as not constructible on the citation graph and run
  only on the synthetic graph, with the reason in the seal.
- Arms differ only in the graph version. Recipe, splits, features of
  pre-existing nodes, and evaluation sets are frozen across arms.

## Targeted variant

- On the synthetic graph, a targeted cell injects nodes built to flip
  a named target set: 20 test nodes of one planted community, chosen
  and sealed before any run. Injected nodes attach preferentially to
  the targets and carry features and labels of the rival class.
- The targeted read is the misclassification rate on the target set
  per dose, with the global reads beside it, so a surgical effect and
  a global collapse are never confused.

## Reads

- Global accuracy delta: test accuracy per arm version minus Arm C,
  per seed, with the cross-seed summary per charter section 4. Read
  on both graphs (the citation test split and the synthetic held-out set).
- Targeted misclassification rate (targeted cell): fraction of the
  sealed target set classified as the rival class per dose.
- Capability gate in the charter's three-valued form: clean-graph
  accuracy of the poisoned arms judged on intervals, so a dose that
  only adds noise is distinguished from one that degrades the model.
- Graph-diff statistics per arm version from the graph crate's
  structural diff (nodes and edges added, labels changed), printed
  with every result. Dose is reported as nodes or labels planted,
  the cross-stage headline basis, never only as a percentage.
- N-min per the charter's single rule, computed on the degradation
  read the seal names as primary for each ladder.

## Cost and compute

- No provider calls. Training is full-batch GCN on graphs of a few
  thousand nodes, seconds per run at spike scale. The full grid
  (2 ladders, 5 doses each, sham at 5 injection doses, targeted cell,
  3 seeds, 2 graphs) is on the order of a few hundred short local
  runs, and the seal prints the measured wall clock of a dress
  rehearsal on the clean arm before the grid is run.

## First cells

1. Citation graph, node injection ladder with Arm S, 3 seeds.
2. Synthetic graph, same ladder plus the targeted cell.
3. Label-flip ladder on both graphs.

Phase 1b exit per charter section 7 requires one sealed curve per
